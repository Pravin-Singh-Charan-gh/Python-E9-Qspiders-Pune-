Termination/Jump Statement

They are the Statement block used to take early exit from a loop or skip some iteration of a loop .

=> There are 3 types of Termination/Jump conditions
i) break
ii)continue
iii) pass

I) break : 
It is used to terminate/stop the loop. 
NOTE : break is a keyword. 
SYNTAX : for var in collection :
            if <condition>:
                break 
EX1 
a = [
    'photography','designing','sports','riding','book writing','playing',87,23,23,56,334
]

for i in a:
    if type(i)==int:
        break
    print(i)
NOTE :    
=> NOTE : break cannot be written outside the loop  
          break should be written in a loop with a condtional Statement or else the loop will execute even once

          a = [1,2,3,4,5]
          for i in a:
            break
            print(i) # not esecutes
          for in a:
            print(i) #executes once
            break


        ERROR ==========

II) continue
-> It is used to skip an iteration of a loop
NOTE : continue is a keyword
SYNTAX : 
for var in collection:
    if <condition>:
        continue

EX1
a = ['a','dsfs','sdfsd',3,34,5,6,7,'dsds',2,675,68,'sdfs']

for i in a:
    if type(i)==int:
        continue
    print(i)

NOTE :
-> Just like break, continue cannot be written outside a loop and should be written in a loop with a conditional Statement
   EX  if 10%2 

   a = [1,2,3,4,5]
   for i in a:
        continue
        print(i)

    for i in a:
        print(i)
        continue

===================================================================================================================

III) pass
-> Pass is a keyword which does nothing or acts a placeholder to avoid indentation ERROR
EG :
pass 
for i in [1,2,34]:
    pass 
if i == 34:
    pass
