Types of data structures and their implementation

(A) Primitive data structures
    Integer, float, character, boolean

(B) Linear data structures (non primitive)
    (i)      Arrays
    (ii)     Matrix
    (iii)    String
    (iv)     Linked List
    (v)      Stack
    (vi)     Queue

(C) Non-linear data strucutres (non-primitive)
    (i) Trees (hierarchical)
        (a)Binary Trees
        (b) Binary Search Tree 
        (c) Self-balancing Trees
                eg AVL Trees. Red-black Trees
        (d) Heap
                min heap and max heap 
        (e) Trie(Prefix Tree)
        (f) Segment Tree/ Fenwick Tree(Binary Indexed Tree)
    
    (ii) Graphs (Networked)
        (a)  Directed Vs Undirected Graphs 
        (b)  Weighted Vs Unweighted
        (c)  Representations : Adjancy Matrix(2D Array) or Adjancency List

(D) Hashing Data Structures
    (i)Hashmap
    (ii)Hash Set
